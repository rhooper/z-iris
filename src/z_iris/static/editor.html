The most specific rule wins: topic, keyword, mention, channel, group DM, DM. Priority overrides that. Comments in your config file are kept.

Volume

How loud a message plays: the rule's volume (or the default rule volume when the rule sets none), times its server's volume, times the master volume. Example: rule 80%, server 50%, master 100% plays at 40%.
